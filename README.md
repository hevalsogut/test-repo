# My First React App 🚀

A simple beginner-level React project built with [Vite](https://vite.dev/).

## What is this?

This is a starter React application. It shows a counter button and links to official documentation — a great starting point for learning React!

## Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (version 18 or higher) installed on your computer.

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to see the app.

3. **Build for production**
   ```bash
   npm run build
   ```

## Project Structure

```
my-first-react-app/
├── public/          # Static assets
├── src/
│   ├── assets/      # Images and icons
│   ├── App.css      # Styles for the App component
│   ├── App.jsx      # Main App component
│   ├── index.css    # Global styles
│   └── main.jsx     # Entry point
├── index.html       # HTML template
├── package.json     # Project dependencies
└── vite.config.js   # Vite configuration
```

## Key Concepts for Beginners

- **Component**: A reusable piece of UI. `App.jsx` is a component.
- **JSX**: HTML-like syntax used inside JavaScript files.
- **useState**: A React hook that lets you add state (changing data) to a component.
- **Props**: Data passed from a parent component to a child component.
